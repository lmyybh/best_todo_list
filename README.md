# todo

一款使用 Flutter 构建的 macOS 本地事件树 Todo 应用。节点没有固定的“事件”或“任务”类型：有子节点时是事件，没有子节点时就是可完成的任务。

界面基于 Material 3 和 Flutter 官方控件，采用暖灰纸张与深青绿的浅色桌面设计。当前只维护 macOS 运行目标，暂不考虑手机端。

## 当前功能

### 事件总览

- 同时展示多个顶层事件卡片，窗口宽度变化时自动调整为 1～4 列
- 在卡片中查看任务树、展开或折叠分支，并直接完成叶子任务
- 卡片默认预览三层任务结构；更深层级可进入详情继续查看和编辑
- 从卡片底部快速添加直接子任务，也可以在任意任务行上继续添加子任务
- 双击任务标题或按 `F2` 原地重命名；顶层事件可通过卡片菜单重命名
- 拖动顶层卡片调整事件顺序，拖动任务行调整同一父节点下的顺序
- 删除节点时软删除整棵子树；从详情删除后可在提示消失前撤销

### 节点详情

- 点击事件或任务标题打开右侧详情面板，点击面板外空白处或“关闭详情”返回总览
- 编辑标题和备注，查看创建时间、完成时间及任务进度
- 设置仅日期的截止期限，或进一步指定精确到分钟的时间
- 快速添加、打开、完成及拖动排序直接子任务
- 叶子任务可以完成或取消完成；事件状态由所有后代叶子任务自动汇总

### 时间线

- 使用“连续 6 天 + 更晚”的日期条浏览任务
- 按周向前或向后切换，并可随时回到今天
- 今天的列表会将逾期未完成任务单独置顶
- 已完成任务按实际完成日期归档，并按完成时间倒序显示
- “更晚”包含当前日期窗口之后的未完成任务，以及未设置截止日期的叶子任务
- 时间线中的条目保留所属路径；点击后会跳转到对应节点详情

### 本地数据

- 使用 SQLite 文件 `best_todo_list.sqlite` 持久化节点、层级、排序、备注、截止时间和完成状态
- 数据保存在本机，不需要账号或网络连接
- 关闭最后一个窗口后应用仍会运行；重新点击应用可恢复窗口，使用 `Command+Q` 完全退出

## 常用操作

| 操作 | 鼠标 / 键盘 |
| --- | --- |
| 新建顶层事件 | 点击左侧导航栏的 `+`，或事件总览末尾的“新建事件”卡片 |
| 快速添加子任务 | 点击卡片底部“添加任务”，或悬停任务行后点击 `+` |
| 完成任务 | 点击叶子任务前的圆点 |
| 打开详情 | 点击事件卡片标题或任务行 |
| 原地重命名任务 | 双击任务标题，或聚焦任务行后按 `F2` |
| 保存 / 取消内联编辑 | `Enter` / `Esc` |
| 调整事件顺序 | 拖动卡片标题区；聚焦后按 `⌥` + 方向键移动一步，增加 `Shift` 移到首尾 |
| 调整同级任务顺序 | 拖动任务行手柄；聚焦后按 `⌥↑` / `⌥↓`，增加 `Shift` 移到首尾 |
| 切换时间线日期 | `←` / `→` |
| 取消正在进行的拖动 | `Esc` |

## 当前不包含

账号与同步、提醒、搜索、标签、优先级、重复任务、附件、导入导出、回收站，以及时间线拖拽改期。目前也没有手机或平板布局。

## 运行

环境要求：

- macOS 及对应的桌面开发工具链
- Flutter 3.44 或兼容的稳定版本
- Dart 3.12 或兼容版本（见 `pubspec.yaml`）

开发调试并实时查看改动：

```sh
flutter pub get
flutter run -d macos
```

应用运行后，在终端按 `r` 热重载，按 `R` 热重启，按 `q` 退出。

## 构建 macOS App

在项目根目录执行 Release 构建：

```sh
flutter pub get
flutter build macos --release
```

构建产物位于：

```text
build/macos/Build/Products/Release/todo.app
```

可以使用以下命令直接打开：

```sh
open build/macos/Build/Products/Release/todo.app
```

## 检查与测试

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build macos --release
```

自动化测试覆盖节点树规则、同级排序、时间线日期边界、SQLite 升级与重开恢复，以及事件总览、详情和截止日期等核心 Widget 流程。

## 项目结构

```text
lib/
  app/       应用入口、状态控制器和主题
  data/      SQLite 数据库与 Repository 实现
  domain/    Node 模型、事件树规则和时间线查询
  ui/        事件总览与详情、时间线、桌面外壳和公共组件
test/        领域、数据、控制器和 Widget 测试
docs/        产品目标与开发计划
prototype/   HTML/CSS 视觉原型
```
